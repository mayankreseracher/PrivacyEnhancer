# Security Policy

## Reporting Security Issues

TrackerControl PC is designed to safeguard user privacy, firewall rules, and network traffic. If you discover a security vulnerability or bypass:

1. **Do not open a public GitHub issue.**
2. Send a detailed description of the vulnerability, reproduction steps, and platform details to `security@trackercontrol.org` or via private GitHub Security Advisory.
3. We will acknowledge receipt within 48 hours and work with you on a coordinated fix.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |
